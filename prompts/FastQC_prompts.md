# FastQC - Coding Agent Prompts

## Prompt 1 - Identify input file formats

Analyze this repository and identify all input file formats accepted by FastQC.

For each input:
- provide the file format;
- describe the biological data type;
- provide evidence from README files, documentation, examples, tests, or source code.

Focus on finding information from:
- README files;
- command-line arguments;
- parser classes;
- file detection code;
- test files.

---

## Prompt 2 - Identify output files

Analyze this repository and identify all output files generated by FastQC.

For each output:
- provide the file name;
- provide the file format;
- describe the purpose of the output;
- provide evidence from source code, documentation, or tests.

Focus especially on:
- report generation code;
- writer classes;
- output templates;
- integration tests.

---

## Prompt 3 - Suggest EDAM ontology terms

Based on the identified input and output files, suggest appropriate EDAM ontology terms.

For each item:
- provide the EDAM term name;
- provide the EDAM ID;
- specify whether it is a data type or file format;
- provide a confidence level;
- explain why the term matches the input/output.

Mention any uncertain mappings that require manual verification.

---

## Prompt 4 - Find additional supported formats

Analyze the repository and identify any additional input or output formats that are not clearly mentioned in the README.

Search for evidence in:
- source code;
- file filters;
- parser implementations;
- test files;
- configuration files.

For each format, explain whether it is a primary supported format or an internal/additional format.

---

## Prompt 5 - Evaluate confidence of extracted information

Review the identified input/output formats and classify each item according to confidence:

- High confidence: clearly documented or confirmed by source code.
- Medium confidence: supported by code but less documented.
- Low confidence: suggested by indirect evidence only.

Provide the evidence supporting each classification.
