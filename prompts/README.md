# Coding Agent Prompts

This directory contains the prompts used to guide AI coding agents during the bioinformatics tool analysis.

## Prompt Structure

The prompts are organized into:

* **General prompt** — common instructions for analyzing bioinformatics repositories.
* **Tool-specific prompts** — adapted prompts for each analyzed tool.

## Files

| File                  | Description                          |
| --------------------- | ------------------------------------ |
| `copilot_prompts.md`  | General coding-agent analysis prompt |
| `FastQC_prompts.md`   | FastQC-specific analysis prompts     |
| `BWA_prompts.md`      | BWA-specific analysis prompts        |
| `SAMtools_prompts.md` | SAMtools-specific analysis prompts   |

The prompts focus on identifying input and output formats, collecting repository evidence, mapping formats to EDAM ontology terms, and documenting uncertainty.
