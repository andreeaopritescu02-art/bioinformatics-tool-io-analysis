# Results

This directory contains consolidated results produced during the analysis of the selected bioinformatics tools.

## Contents

| File                              | Description                                                              |
| --------------------------------- | ------------------------------------------------------------------------ |
| `tools_comparison.md`             | Comparison of the input/output format findings across the analyzed tools |
| `samtools_edam_verification.md`   | Human-readable report of the SAMtools EDAM mapping verification          |
| `samtools_edam_verification.json` | Structured SAMtools EDAM verification results                            |

The results complement the detailed tool-specific analyses located in the `tools/` directory.
