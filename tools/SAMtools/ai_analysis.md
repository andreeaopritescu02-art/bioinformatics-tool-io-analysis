## AI Results

### SAM

Biological data: Sequence alignment records in the text-based Sequence Alignment/Map format.

Evidence found by AI:

- README mentions SAM as a supported alignment format.
- `doc/samtools-view.1` describes SAM input.
- `sam_view.c` uses the SAMtools/HTSlib alignment-file reading interface.

### BAM

Biological data: Binary compressed alignment records.

Evidence found by AI:

- README mentions BAM as a supported alignment format.
- `doc/samtools-view.1` documents BAM input.
- `bedcov.c` opens alignment files using `sam_open_format()`.

### CRAM

Biological data: Reference-aware compressed alignment records.

Evidence found by AI:

- README mentions CRAM as a supported alignment format.
- `doc/samtools-view.1` documents CRAM input.
- `bam_plcmd.c` uses `sam_open_format()` and CRAM-specific options.

### FASTQ

Biological data: Sequencing reads with per-base quality scores.

Evidence found by AI:

- `bam_import.c` implements the `samtools import` command.
- `doc/samtools-import.1` describes reading FASTQ files.
- Compressed FASTQ input is supported.

### FASTA

Biological data: Reference nucleotide sequences.

Evidence found by AI:

- `faidx.c` implements FASTA indexing and sequence retrieval.
- `dict.c` reads FASTA files using `gzopen()`.
- `doc/samtools-dict.1` documents FASTA input.

### BED

Biological data: Genomic regions or features.

Evidence found by AI:

- `bedcov.c` reads BED files containing genomic regions.
- `doc/samtools-bedcov.1` documents BED input.
- BED records are parsed directly by the command implementation.

### Auxiliary index files

AI also identified several auxiliary files used by SAMtools:

- FAI (`.fa.fai`, `.fasta.fai`) - FASTA index files.
- BAI (`.bam.bai`) - BAM index files.
- CSI (`.bam.csi`) - coordinate-sorted index files.
- CRAI (`.cram.crai`) - CRAM index files.

Evidence found by AI:

- `bam_tview.c` and other source files use `fai_load()` and `sam_index_load()`.
- `sam_utils.c` handles index suffixes.
- `doc/samtools-index.1` documents BAI, CSI and CRAI indexes.

FQI (`.fq.fai`) was not included because the agent did not find sufficient evidence that it is read as a standalone auxiliary input.

## AI Results

### BAM

Binary alignment format used to store processed alignment data.

Evidence found by AI:

- `doc/samtools-view.1` documents BAM output.
- `doc/samtools-sort.1` documents BAM as an output format.
- `bam_sort.c` implements BAM file generation.

### SAM

Text-based Sequence Alignment/Map format containing alignment records.

Evidence found by AI:

- `doc/samtools-view.1` documents SAM output.
- `doc/samtools-sort.1` lists SAM as an output format.
- `sam_view.c` handles SAM output.

### CRAM

Reference-based compressed alignment format.

Evidence found by AI:

- `doc/samtools-view.1` documents CRAM output.
- `doc/samtools-sort.1` lists CRAM as an output format.
- SAMtools uses HTSlib format handling for CRAM output.

### FASTA

Sequence format used for extracted or consensus sequences.

Evidence found by AI:

- `doc/samtools-fasta.1` documents FASTA output.
- `doc/samtools-consensus.1` documents FASTA consensus output.
- `bam_fastq.c` implements sequence extraction.

### FASTQ

Sequence format containing reads and per-base quality scores.

Evidence found by AI:

- `doc/samtools-fasta.1` documents FASTQ output.
- `doc/samtools-consensus.1` documents FASTQ consensus output.
- `bam_fastq.c` implements FASTQ output.

### Pileup

Text-based positional consensus output.

Evidence found by AI:

- `doc/samtools-consensus.1` documents pileup output.
- `bam_consensus.c` implements pileup generation.

### Sequence Dictionary

SAM-style text file containing reference sequence metadata.

Evidence found by AI:

- `doc/samtools-dict.1` documents dictionary generation.
- `dict.c` implements dictionary output.

### Auxiliary index files

SAMtools also generates supporting index files:

- BAI (`.bai`) - BAM index;
- CSI (`.csi`) - coordinate-sorted index;
- CRAI (`.crai`) - CRAM index;
- FAI (`.fai`) - FASTA index;
- FQIDX (`.fqidx`) - FASTQ index.

Evidence found by AI:

- `doc/samtools-index.1`
- `doc/samtools-faidx.1`
- `doc/samtools-fqidx.1`
- `bam_index.c`
- `faidx.c`

### Text reports

Several commands generate textual output, including:

- `stats`;
- `flagstat`;
- `idxstats`;
- `depth`;
- `coverage`;
- `mpileup`;
- `ampliconstats`;
- `checksum`;
- `cram-size`.

These are textual command outputs rather than distinct biological file formats.

Evidence found by AI:

- corresponding command documentation in `doc/`;
- corresponding source files.

### Temporary files

Sorting can generate temporary BAM files during processing.

Evidence found by AI:

- `doc/samtools-sort.1`;
- `bam_sort.c`.
