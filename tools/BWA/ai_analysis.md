## AI Results

### FASTA

Biological data: Reference DNA sequences used by BWA to build the reference index.

Evidence found by AI:

* `bwa.1` documents `bwa index [options] <in.fasta>`.
* `bwa.1` explicitly states that the reference sequences are provided in FASTA format.
* `bwtindex.c` contains the FASTA input handling for reference indexing.
* `README.md` provides examples using reference FASTA files.

### FASTQ

Biological data: Sequencing reads containing nucleotide sequences and quality scores.

Evidence found by AI:

* `bwa.1` provides `bwa mem` examples using `.fq` files.
* `bwa.1` documents `<in1.fq>` and `<in2.fq>` as read inputs.
* `fastmap.c` contains FASTQ input handling.
* `README.md` provides examples using FASTQ files.

### BAM

Biological data: Binary sequencing-read data that can be used as an alternative input to FASTQ in BWA-backtrack.

Evidence found by AI:

* `bwa.1` documents the `-b` option for BAM input.
* `bwa.1` provides examples using BAM files with `bwa aln` and `bwa sampe`.
* `bwtaln.c` implements the BAM input option.

### Interleaved FASTQ

Biological data: Paired-end sequencing reads stored in a single interleaved FASTQ stream.

Evidence found by AI:

* `bwa.1` documents the `-p` option for interleaved paired-end reads.
* `fastmap.c` documents smart pairing and interleaved input.

Interleaved FASTQ is a structural variant of FASTQ and is not treated as a separate EDAM format.

## AI Evaluation

The coding agent successfully identified the main input formats supported by BWA and provided evidence from documentation and source code.

The main verified inputs are:

* FASTA;
* FASTQ;
* BAM.

Additional input variants identified by the agent include:

* interleaved FASTQ;
* Illumina 1.3+ FASTQ quality encoding;
* compressed FASTQ input.

These are treated as variants or processing methods of the main formats rather than as separate biological formats.
